# ระบบคิดค่าแรงคนงาน (Wage Management System) v3.0 — Supabase Cloud Edition

เว็บแอปจัดการค่าแรงคนงานรายวันยุคใหม่ พัฒนาต่อยอดจาก Web-Work v2.4 โดยเปลี่ยนระบบฐานข้อมูลจาก **Google Sheets + Google Apps Script** มาเป็น **Supabase (PostgreSQL + Cloud Storage)** เพื่อความเร็วสูงสุดในการบันทึกและโหลดข้อมูล พร้อมระบบสำรองการทำงานในเครื่อง (Local Storage Fallback) ที่ทำให้เปิดใช้งานได้ทันทีแม้ยังไม่ได้ต่อฐานข้อมูลคลาวด์

## 🚀 จุดเด่นของเวอร์ชัน 3.0 (Supabase Edition)

1. **ความเร็วระดับมิลลิวินาที (10x Faster):**
   * ไม่ต้องรอ Google Apps Script ตอบสนองนาน 3–8 วินาทีอีกต่อไป บันทึกใบงานและดึงรายงานได้ทันที
2. **ระบบสั่งงาน ติดตามความคืบหน้า และวิเคราะห์ต้นทุนตามชิ้นงาน (Job Orders & Task Costing):**
   * สั่งงานและติดตามความคืบหน้ารายวัน (0–100%) พร้อมบันทึกประวัติปัญหาและวิธีแก้ไขหน้างานแบบไทม์ไลน์
   * เชื่อมโยงเข้ากับใบงานรายวันอัตโนมัติ คำนวณต้นทุนค่าแรงจริง, ค่าแรงคิดลูกค้า (+20%), วันทำงานจริง, และจำนวนแรงงานรวม (Man-Days)
   * ระบบ **Accumulated Snapshot** คงยอดต้นทุนและแรงงานของงานที่ยังไม่เสร็จอย่างต่อเนื่อง แม้จะกดล้างบันทึกใบงานเพื่อเริ่มรอบเบิกงวดใหม่
3. **อัปโหลดรูปถ่ายหน้างานเข้า Cloud Storage โดยตรง:**
   * บีบอัดรูปด้วย Canvas อัตโนมัติแล้วส่งเข้าคลังไฟล์ `wage-images` บน Supabase Storage เปิดดูรูปในหน้าพิมพ์รายงานได้รวดเร็วไม่ติดบล็อกของ Google Drive
4. **ทำงานได้ 2 โหมดอัตโนมัติ (Dual-Mode):**
   * **โหมดคลาวด์ (Supabase Cloud):** ออนไลน์เต็มรูปแบบ ใช้ร่วมกันระหว่างมือถือที่หน้าไซต์งานและคอมพิวเตอร์ที่ออฟฟิศ
   * **โหมดบันทึกในเครื่อง (Local Mode):** เปิดไฟล์เว็บขึ้นมาใช้งานและทดสอบได้ทันทีโดยไม่ต้องตั้งค่าเซิร์ฟเวอร์
5. **ตั้งค่าคลาวด์ผ่านหน้าเว็บได้ทันที:**
   * คลิกปุ่ม **"⚙️ ตั้งค่าคลาวด์ (Supabase)"** ที่แถบเมนูซ้ายมือ เพื่อวาง `Project URL` และ `Anon Key` บนหน้าจอเว็บได้โดยตรง ไม่ต้องแก้โค้ด
6. **กฎการคำนวณและฟีเจอร์เดิมครบ 100%:**
   * คำนวณรายชั่วโมง (หาร 8 ชม.), OT คิด 2 เท่า, เหมาจ่ายไม่คิด +20%, ยกเว้น +20% สำหรับคนงานชื่อ `"เฟิร์น"`
   * ระบบ **"เบิกงวด" (Backup & Restore)** สำรองข้อมูลใบงานเก็บไว้ในตาราง `log_backups` และดาวน์โหลดเป็นไฟล์ `.json` เก็บลงคอมพิวเตอร์ได้
   * รหัสผ่าน PIN สำหรับจัดการคนงานและสำรองข้อมูล: **`1225`**
