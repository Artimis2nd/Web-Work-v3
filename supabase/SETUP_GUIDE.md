# คู่มือการตั้งค่าฐานข้อมูลคลาวด์ฟรี (Supabase) แบบจับมือทำ

คุณสามารถสร้างฐานข้อมูลออนไลน์ส่วนตัวได้ฟรีภายใน 2 นาที โดยไม่ต้องใช้ Google Sheets หรือ Google Drive อีกต่อไป:

---

### ขั้นตอนที่ 1: สมัครและสร้างโปรเจกต์ฟรีบน Supabase
1. เข้าไปที่เว็บไซต์ **[https://supabase.com](https://supabase.com)**
2. กดปุ่ม **"Start your project"** แล้วล็อกอินด้วยบัญชี **GitHub** ของคุณ (`Artimis2nd`) ได้เลย
3. กดปุ่ม **"New Project"** (สร้างโปรเจกต์ใหม่):
   * **Name (ชื่อโปรเจกต์):** ตั้งชื่อ เช่น `wage-work-db`
   * **Database Password (รหัสผ่านฐานข้อมูล):** ตั้งรหัสผ่านอะไรก็ได้แล้วจดไว้ (หรือกด Generate a password)
   * **Region (ตำแหน่งเซิร์ฟเวอร์):** เลือก **`Southeast Asia (Singapore)`** เพื่อให้โหลดในไทยเร็วที่สุด
4. กดปุ่ม **"Create new project"** แล้วรอระบบสร้างตู้ข้อมูลประมาณ 1 นาที

---

### ขั้นตอนที่ 2: สร้างตารางข้อมูลและคลังเก็บรูปภาพในคลิกเดียว
1. เมื่อโปรเจกต์สร้างเสร็จแล้ว ให้ดูที่เมนูแถบซ้ายมือ คลิกที่ไอคอน **`SQL Editor`** (สัญลักษณ์ `>_`)
2. กดปุ่ม **"+ New query"**
3. เปิดไฟล์ [`schema.sql`](file:///e:/#Antigravity/apps/wage-app/supabase/schema.sql) ในโปรเจกต์นี้ คัดลอกโค้ดข้างในทั้งหมดไปวางในช่องว่างบนเว็บ Supabase
4. กดปุ่มสีเขียว **"Run"** (มุมขวาล่าง)
   * เมื่อขึ้นข้อความ `Success. No rows returned` แปลว่าระบบสร้างตาราง `workers`, `daily_logs`, `log_images`, `log_backups` และคลังรูปภาพ `wage-images` เสร็จสมบูรณ์แล้ว!

---

### ขั้นตอนที่ 3: นำกุญแจเชื่อมต่อ (URL & API Key) มาใส่ในเว็บแอป
1. ที่แถบเมนูซ้ายมือของ Supabase คลิกที่ไอคอนรูปเฟือง **`Project Settings`** (ด้านล่างสุด) -> เลือกเมนู **`API`** (หรือกดปุ่ม `Connect` ด้านบนสุดของหน้าเว็บ)
2. คัดลอกค่า 2 ตัวนี้มาเก็บไว้:
   * **Project URL:** (เช่น `https://xxxxxxxxxxxx.supabase.co`)
   * **Project API Keys (`anon` / `public`):** (รหัสยาวๆ ที่ขึ้นต้นด้วย `eyJ...`)
3. นำค่าทั้ง 2 ตัวนี้มาวางในไฟล์ `assets/js/config.js` ของเว็บแอป (หรือกรอกผ่านหน้าตั้งค่าบนเว็บแอปที่เรากำลังจะสร้างในขั้นตอนถัดไปได้เลยครับ)
